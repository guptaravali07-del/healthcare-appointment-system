# Healthcare Appointment System

## Project Overview

A Java-based desktop application that simulates healthcare appointment booking through a graphical user interface built using Java Swing.

This personal project demonstrates core Java programming, user interface development, input validation, exception handling, and event-driven programming.

## Features

- Patient information entry
- Doctor selection dropdown
- Appointment date entry
- Appointment time selection
- Patient age validation
- Empty field validation
- Appointment confirmation popup
- Form reset functionality
- User-friendly graphical interface

## Technologies Used

- Java
- Java Swing
- Java AWT
- Eclipse IDE
- GitHub

## How to Run

1. Download or clone this repository.
2. Create a Java project in Eclipse.
3. Copy the source files into the project's src folder.
4. Open AppointmentUI.java.
5. Run as a Java Application.
